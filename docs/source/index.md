# PNCP em Números

**Guia de Utilização do Painel de Análise de Contratações Públicas**

---

O **PNCP em Números** é um painel desenvolvido em Power BI que consolida dados do
[Portal Nacional de Contratações Públicas (PNCP)](https://pncp.gov.br), permitindo
a análise de contratações públicas brasileiras sob diferentes perspectivas:
temporal, territorial, institucional e mercadológica.

Este manual documenta as três páginas do painel e orienta o usuário sobre como
interpretar os indicadores e extrair análises relevantes.

## Páginas do painel

| Página | O que analisa |
|---|---|
| **Visão Geral** | Panorama nacional: KPIs, tendência temporal, mapas, esfera, modalidade e situação das contratações |
| **Contratações Publicadas** | Intenção de contratação: órgãos, modalidades, instrumentos, critérios e filtros da etapa de publicação |
| **Contratações Homologadas** | Resultado efetivo: fornecedores, valores homologados, porte, natureza jurídica e contratações internacionais |

## Como usar este manual

Navegue pelo sumário lateral para acessar diretamente a seção de interesse.
O manual pode ser lido de forma linear ou consultado pontualmente por seção.
